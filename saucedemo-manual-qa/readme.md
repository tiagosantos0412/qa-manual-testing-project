# SauceDemo Manual QA

Projeto de QA Manual desenvolvido com foco em análise de requisitos, regras de negócio, cenários de testes, casos de teste, execução de testes e reporte de bugs utilizando a aplicação pública SauceDemo.

## Objetivo

Este repositório tem como objetivo demonstrar habilidades em:

- Levantamento de requisitos
- Escrita de regras de negócio
- Criação de cenários de testes
- Elaboração de casos de teste
- Reporte de bugs
- Execução de testes manuais
- Organização de evidências
- Estruturação de documentação QA

---

# Aplicação Utilizada

- Sistema: https://www.saucedemo.com/
- Tipo: E-commerce
- Plataforma utilizada para estudos e prática de testes manuais.
